# dsh-memory-nebula · 记忆星云

给 [DeepSeek Harness](https://github.com/deepseek-ai) 桌面端用的记忆插件。不是记事本，是**会自己记事、自己按话题想起来**的长期记忆。

- 每轮对话前，按你这句话去记忆库里检索，只把相关的那几条塞进上下文
- 平时它不说话；想不起来的时候它会说「这一刻没有相关的」，不占思考
- 记忆会随时间衰减（45 天半衰期），常被想起来的会更牢
- 侧栏有一张能转、能点、能钻进去的星云图

## 它解决什么

上下文窗口是有限的。聊天记录越长，模型越只看得见最近几屏，人会「忘事」。

这个插件把值得长期记住的东西（偏好、决定、教训、人物、待办）抽出来存成独立节点，每轮只挑跟当前话题相关的几条塞回去。等于给模型装了一层可检索的长期记忆，而不是把所有历史都堆在 prompt 里。

## 功能

**7 个工具**

| 工具 | 干什么 |
| --- | --- |
| `memory_save` | 记一条。自动去重、自动和相似记忆连线；`closes` 可以顺手收掉一条待办 |
| `memory_search` | 检索：字面命中 → 顺连线联想扩散 → 按鲜活程度排序，带 `why` 说明为什么想到它 |
| `memory_get` | 按 id 取完整内容，连带邻居一起 |
| `memory_link` | 手动连两条记忆 |
| `memory_forget` | 删掉一条（连同它的连线） |
| `memory_pin` | 钉住/取消钉住。钉住的不吃时间衰减 |
| `memory_stats` | 库里有多少条、多少连线、孤立的几条、各层各类型的分布 |

**五种视图**

- **小银河** — 中心核 + 星系臂，六个大类各是一颗行星，自己转
- **星云** — 3D 力导向，三层递归分层（核心 → 一级层 → 二级类型 → 三级标签 → 末位记忆）
- **聚类** — 同类型抱团
- **时间轴** — 按记录时间铺开
- **列表** — 一行一条，方便查找和编辑

点类别会自动聚焦，以那个点为新核心重新排布；拖拽可以旋转，松手有惯性。悬停节点出卡片，显示标题、所属、连线数、标签和正文开头。

**六层分类**：核心 / 记忆 / 指令 / 能力 / 服务 / 数据

**待办有状态**：`open` / `done` / `parked`。待办完成后自动划线，写完成记录时按标题重合度自动收掉对应待办。

## 安装

要求 DSH 桌面端（插件形式为 host + web client 两半）。

```bash
# 从源码目录链进 profile
dsh plugin --profile desktop add link:C:/path/to/dsh-memory-net
```

或者把目录放进 `~/.dsh/plugins/`，用插件管理器安装。

## 数据

全部落在 `~/.dsh/memory-net/graph.json`，原子写（tmp → rename），失败只留在内存不脏盘。删掉这个文件等于清空记忆。

## 结构

```
lib/index.js    host 侧：7 个工具、系统提示注入、/api/dsh-memory-nebula 路由
lib/store.js    存储、检索打分、连线、衰减、注入文本
lib/client.js   侧栏面板与画布（React + Canvas 2D，无第三方依赖）
cordis.patch.yml 挂载点
```
